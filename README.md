# Vibe Shopping - Shopping List App

A modern, beautiful shopping list application built with React (no npm required).

## Features

- **Thing Input**: Required text field to add items to your shopping list
- **Amount Input**: Optional field for quantities and measurements (e.g., "2 lbs", "1 gallon")
- **Store Multi-Select**: Optional dropdown with multiple store options:
  - Hmart
  - 99 Ranch
  - Trader Joe's
  - Costco
  - Farmer's Market
  - Selected stores appear as pillboxes with dismissible "×" buttons
  - Can be deselected from the dropdown when expanded

## Getting Started

### No Installation Required!

Simply open `index.html` in your web browser. That's it!

The app uses React via CDN, so you don't need npm, Node.js, or any build tools. Just double-click the `index.html` file or open it in any modern web browser.

### Features Included

- ✅ Required "Thing" text input field
- ✅ Optional "Amount" field
- ✅ Multi-select store dropdown with all 5 stores
- ✅ Pillbox display for selected stores with dismissible "×" buttons
- ✅ Checkbox selection/deselection in dropdown
- ✅ Shopping list display with all item information
- ✅ Delete items from the list
- ✅ Beautiful, modern UI with animations
- ✅ Responsive design

## Usage

1. Open `index.html` in your browser
2. Enter an item in the "Thing" field (required)
3. Optionally add an amount and select stores
4. Click "Add to List" to add the item
5. Items appear in the shopping list below
6. Delete items by clicking the "×" button

## Tech Stack

- React 18 (via CDN)
- Vanilla JavaScript
- CSS3 (with modern animations and gradients)

No build tools, no npm, no installation required!
